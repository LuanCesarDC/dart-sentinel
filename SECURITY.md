# Security Policy

## Supported versions

Only the latest published release of `dart_sentinel` receives fixes.

## Reporting a vulnerability

Please **do not open a public issue** for security problems. Use GitHub's
private vulnerability reporting ("Security" tab → "Report a vulnerability")
on https://github.com/LuanCesarDC/dart-sentinel, with a description and, if
possible, a minimal reproduction.

You can expect an acknowledgement within a few days. Dart Sentinel reads
project files and writes only `.dart_sentinel/` and, on request,
`analyzer.yaml` and `.claude/settings.json`; it makes no network calls.
